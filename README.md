Este projeto foi desenvolvido como uma atividade prática para a graduação em **Análise e Desenvolvimento de Sistemas** no Centro Universitário Maurício de Nassau. O foco principal foi explorar os novos recursos do Angular 19 e a criação de interfaces modulares.

⚠️ **NOTA DE ESCOPO:** Este repositório possui finalidade estritamente **acadêmica** e foi criado para uma **apresentação em sala de aula**. O projeto serve como portfólio de estudo e não possui planos para publicação em ambiente de produção ou uso comercial.

## 🚀 Destaques Técnicos

A aplicação foi estruturada utilizando as funcionalidades mais recentes do ecossistema Angular:

* **Arquitetura Standalone:** Implementação de componentes independentes (Standalone Components), eliminando a necessidade de NgModules e tornando o código mais limpo e performático.
* **Serviços e Lógica de Negócio:** * `OrcamentoService`: Gerenciamento centralizado de solicitações de orçamentos.
    * `AuthService`: Simulação de fluxo de autenticação e proteção de estado do usuário.
* **Roteamento Avançado:** Sistema de rotas dinâmicas com tratamento de páginas "Não Encontrado" (404) e navegação entre seções.
* **Modularização de UI:** Componentização total da interface, incluindo `Hero-Carousel`, `Catálogo de Produtos`, `Seção Sobre` e formulários de `Contato`.

## 🛠️ Tecnologias Utilizadas
- **Core:** Angular v19
- **Linguagem:** TypeScript (Tipagem forte e interfaces)
- **Estilização:** CSS3 com foco em design responsivo
- **Tooling:** Angular CLI e Node.js

## 📂 Estrutura do Projeto
Para facilitar a demonstração em sala, o código foi organizado da seguinte forma:
- `src/app/components/`: Componentes reutilizáveis da interface.
- `src/app/paginas/`: Views principais do sistema (Home, Login, Erro).
- `src/app/services/`: Camada de serviços para integração de dados e lógica.
- `src/app/app.routes.ts`: Definição centralizada da árvore de navegação.
